# 로또 번호 생성기 개편 — 법률 검토 요청 문서 (2026-09-30)

이 문서는 외부 법률 검토에 전달하기 위해 작성했습니다. 하루콕 운영자가 내부적으로 정리한 자료이며,
**"자체 디자인·면책문구를 적용했으니 법적으로 문제없다"는 결론을 내리는 문서가 아닙니다.**
아래 기능은 시안 단계이며, 이 문서의 검토와 법률 확인이 끝나기 전까지 운영 사이트(harukok.com)에 공개하지 않습니다.

## 1. 배경

- 대상: `/fun/lotto-generator` (기존 URL·기록·기능 보존)
- 변경 요지: 기존 "1게임 뽑기" 버튼을 "가상 금액(1,000~5,000원) 선택 → 1~5줄 번호 생성"으로 바꾸고,
  결과를 하루콕 자체 디자인의 종이형 "번호 메모"로 보여주며, 이미지 저장·텍스트 복사·공유 링크 기능을 추가.
- 실제 결제·충전·구매대행·번호 판매·경품(현금·상품) 지급 기능은 없음. "가상 금액"은 줄 수를 정하는 표시일 뿐,
  현금 가치나 포인트로 동작하지 않음.
- 이용자에게 번호 생성 비용을 받지 않으며, 사이트는 광고 수익화를 계획합니다. "무료 제공"은 이용자가 이 도구를 쓰는 데
  대가를 지불하지 않는다는 뜻이며, 하루콕이 비영리로 운영된다는 의미가 아닙니다. 하루콕은 Google AdSense 광고 게재를
  통한 수익화를 목표로 하는 상업적 웹사이트입니다.

## 2. 기능 명세 (시안 기준)

### 2.1 입력·생성
- 가상 금액 5단계: 1,000 / 2,000 / 3,000 / 4,000 / 5,000원 → 각각 1 / 2 / 3 / 4 / 5줄.
- 각 줄: 1~45 중 서로 다른 정수 6개, 오름차순 정렬.
- 같은 묶음 내 완전히 동일한 조합(6개 숫자 전부 일치)은 재생성하여 방지. 일부 숫자 중복, 과거 기록과의 동일 조합은 허용.
- 버튼 라벨: "번호 생성" (구매/결제/발권 문구 사용하지 않음).
- 결제·충전·잔액 차감 로직 없음 — "가상 금액"은 UI 표시 및 줄 수 매핑 값일 뿐 서버·클라이언트 어디에도 잔액으로 저장되지 않음.

### 2.2 결과 표시
- 하루콕 자체 디자인의 "번호 메모" 카드: 상단 "하루콕 번호 메모", 행별 번호, 하단 "가상 금액 N원 · N줄 · 무료 생성".
- 공식 복권의 발행/추첨/판매점/당첨금 청구 서식(일련번호, 검증 바코드, 발권번호, 회차 표기 등)을 재현하지 않음.
- 화면과 저장 이미지·공유 텍스트 모두에 다음 문구를 항상 표시:
  **"하루콕 무료 번호 생성 결과 · 실제 복권 아님 · 구매 및 당첨금 청구 효력 없음"**
- "동행복권과 무관한 서비스"임을 별도로 명시.
- AI 당첨 예측, 확률 향상, 당첨 보장, 공식 제휴로 오해할 수 있는 표현 사용하지 않음.

### 2.3 기록 호환
- 기존 `localStorage` 키(`harukok-lotto-history`)와 기존 레코드 구조(`{nums:number[6], date}`, 1줄 단위)를 계속 읽고 표시.
- 신규 저장 형식(묶음 단위, 1~5줄)으로 확장하되 최소한의 하위 호환 처리 포함 — 기존 레코드를 삭제·강제 변환하지 않음.

### 2.4 저장·복사·공유
- **이미지로 저장**: 화면에 표시된 묶음 전체(1~5줄)와 면책 문구가 포함된 이미지 생성.
- **텍스트 복사**: 같은 내용(가상 금액·줄 수·번호·면책 문구)을 텍스트로 클립보드에 복사.
- **공유 링크**: URL fragment(`#` 뒤)에 번호 묶음 데이터만 담아 서버에 저장하지 않는 방식을 우선 검토. 공유 링크를 연 사람에게는:
  - "공유된 결과입니다 · 열람만 가능" 배지 표시.
  - 열람 시 재추첨하지 않음 (표시된 번호 그대로).
  - 방문만으로 열람자의 로컬 기록을 덮어쓰지 않음.
  - 유효 묶음 수(1~5)·번호 범위(1~45)·중복 여부를 파싱 시 검증하고, 값이 올바르지 않으면 안전하게 오류 처리.
  - 개별 공유 링크는 sitemap에 넣지 않고 `canonical`은 기본 생성기 주소로 유지.

### 2.5 디자인 근거 자료
- 사용자가 제공한 워터마크 참고 이미지는 "분위기 참고"로만 사용했고, 이미지·벡터·로고·워터마크를 복제하거나 워터마크를 제거하지 않았습니다.
- 공식 로고·용지 사진·스크린샷·추첨 방송 자료를 사용하지 않았습니다.
- 시안 링크(Claude Artifact, 비공개): 별도로 전달.

## 4. 확인하지 못한 쟁점 (외부 법률 검토가 필요한 부분)

1. **복권 및 복권기금법 핵심 조문 본문** — 웹 도구로 현행 조문 전체를 추출하지 못해, 이용자에게 번호 생성 비용을 받지 않으며 사이트는 광고 수익화를 계획하는 이 서비스가 이 법의 규율 대상에 해당하는지 여부를 조문 원문 기준으로 확정하지 못했습니다.
2. **상표권** — "로또"라는 명칭 자체, 유사 로고·서체 조합에 대한 상표 등록 현황을 검색·확정하지 않았습니다.
3. **부정경쟁방지법상 출처 혼동 가능성** — 최종 시안(색상·서체·레이아웃)이 실제로 일반 소비자에게 동행복권과 혼동을 일으킬 수 있는지는 시안을 본 법률 전문가의 판단이 필요합니다. 면책 문구를 넣었다는 사실만으로 혼동 가능성이 사라진다고 보지 않습니다.
4. **사행성 규제 일반** — 금전·경품 지급이 전혀 없는 설계이지만, "가상 금액"이라는 표현 자체가 규제 기관·플랫폼 정책상 문제로 해석될 여지가 있는지 별도 확인이 필요합니다.
5. **약관·개인정보** — 공유 링크 기능(URL fragment 방식)이 개인정보 보호법상 별도 고지 의무를 발생시키는지 여부는 검토하지 않았습니다(다만 설계상 서버 저장 없음).

## 5. 하루콕의 위험 완화 조치 (참고용 — 법적 결론 아님)

- 금전·경품 지급 없음 (번호 생성·기록·공유로 기능 제한)
- 공식 복권의 로고·이미지·서식·바코드·일련번호 미사용, 독자적 디자인 적용
- "실제 복권 아님", "동행복권과 무관" 문구를 화면·저장 이미지·공유 텍스트에 상시 노출
- 당첨 예측·확률 상승·공식 제휴 암시 표현 배제

**판단 한계**: 위 조치들은 위험을 줄이는 방향의 설계 선택일 뿐이며, 최종 화면이 실물과 충분히 구별되는지, 상표·부정경쟁방지법·복권 관련 법령을 저촉하지 않는지는 이 문서만으로 확정할 수 없습니다. 최종 시안(디자인 링크 포함)과 이 기능 명세를 근거로 전문 법률 검토 또는 권리자 확인을 받은 뒤 공개 여부를 결정해야 합니다.
