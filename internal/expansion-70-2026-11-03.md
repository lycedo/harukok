# 하루콕 도구 70개 확장 인수인계

기록일: 2026-11-03 (한국 시간). 내부 작업 기록이며 공개 배포 대상이 아닙니다.

## 현재 상태

기존 도구 50개에 20개를 추가해 총 70개로 확장했습니다. `tools/` 62개와 `fun/` 8개이며 가이드 본문 6편은 유지했습니다. 이번 작업은 필요한 도구와 사용 설명을 늘리고 홈 검색·관련 링크에서 찾기 쉽게 만드는 데 초점을 맞췄습니다. 실제 검색 순위나 유입 증가를 확인했다는 뜻은 아닙니다.

코드 구현과 정적·기능 검증을 완료했습니다. **신규 20개 도구를 모바일 390px·데스크톱 1280px에서 직접 실행하고 화면을 확인했습니다.** 홈·로또·음식·기존 사진 도구·가이드 목록·가이드 글·소개도 두 너비에서 확인했으며 가로 넘침이나 글자 겹침은 발견하지 못했습니다. 커밋·푸시와 운영 배포는 이 문서 작성 시점에 진행 중입니다. 사용자는 화면 검증 후 문제가 없으면 커밋·푸시·운영 배포하도록 명시적으로 승인했습니다.

## 광고 연결

**모든 도구 70개에 기존 광고 배너를 정확히 1개씩 연결했습니다.** 신규 20개도 `/ad-banner-isolated.js?v=20261027-banner`를 사용합니다. 기존 광고 업체·격리 구조를 유지했으며 새 광고 라이브러리나 별도 광고 계정은 추가하지 않았습니다.

페이지별 광고 코드와 중복 여부를 검사하고 모바일 320×50·데스크톱 468×60 배너 소재의 실제 표시를 확인했습니다. 광고 수익이나 모든 방문에서의 소재 제공을 보장하는 뜻은 아닙니다. 운영 배포 확인은 위에 적은 진행 상태를 따릅니다.

## 검색과 탐색 개선

- 홈에 신규 20개를 추가하고 도구 분류를 10개로 구성했습니다. 분류는 생활 계산, 문서·개발, 수학·학습, 월급, 퇴사, 사진 편집, 추첨·만들기, 만들기·색상, 반려동물, 육아입니다. ‘전체’ 버튼은 별도의 분류 수에 포함하지 않습니다.
- 홈 검색어와 설명을 실제 제공 기능에 맞췄습니다. 신규 도구의 canonical, 제목·설명, 공유 메타와 구조화 데이터를 연결했습니다.
- 사이트맵에 신규 20개를 추가해 검색 대상 페이지가 총 80개가 됐습니다. 도구 70개, 가이드 본문 6편, 가이드 목록, 홈, 소개, 개인정보 페이지를 포함합니다.
- 기존 도구와 신규 도구의 관련 링크를 연결해 계산·문서·이미지·색상 작업을 이어서 할 수 있게 했습니다.
- 물감 배합 비율 계산기의 검색·공유 설명과 본문을 보완했습니다. 목표 HEX 색과 물감 2~4개를 사용하는 화면 혼합 모형의 참고 비율임을 밝히고, 실제 안료·브랜드·농도에 따라 색이 다를 수 있음을 설명합니다. 배합량·사진 색상 추출·색상 변환·대비 도구로 이어지는 링크도 추가했습니다.

## 검증 완료 범위

- `node scripts/check-design.js` 통과.
- `node scripts/build.js` 통과. 소스와 배포 산출물의 검색 메타·사이트맵·내부 링크 검사를 포함합니다.
- 전체 `verify/verify-*.js` 36개 통과. 새 도구의 계산·변환, 입력 경계, 결과 갱신, 복사·저장, 광고 연결 등을 검증했습니다.
- 신규 20개를 두 화면 너비에서 예시 입력으로 실행했습니다. 사진 합치기(1200×600), 워터마크·모자이크(600×400)의 PNG 실제 저장을 확인했습니다. 정규식의 0.75초 시간 초과 중단과 예시 재실행 복구도 브라우저에서 확인했습니다.
- 기존 공통 디자인과 CSS를 사용했으며 외부 라이브러리를 추가하지 않았습니다.
- 내부 문서·검증 스크립트·개발 스크립트는 배포 산출물에 포함하지 않습니다.

## 이어서 할 작업

1. 승인된 범위에서 `dev` 커밋·푸시, 미리보기 확인, `main` 운영 배포를 진행합니다.
2. 배포 완료 뒤 운영 주소의 신규 도구·광고 연결·페이지 응답과 비공개 파일 제외를 확인합니다. Git 푸시 성공만으로 운영 배포 완료를 기록하지 않습니다. 최종 배포 증거와 검색 지표는 Git에서 제외된 `internal/private/`에 보관합니다.

자동으로 도구를 계속 추가하거나 반복 실행하는 작업은 만들지 않았습니다. 이후 확장은 실제 필요와 품질 검증을 기준으로 별도 작업에서 진행합니다.

이전 50개 확장·권한 복구 기록은 [검색 유입 개선 기록](search-growth-2026-11-03.md), 화면 규칙은 [디자인 시스템](design-system.md)을 참고하세요.
