# 운영자 내부 메모 (비공개 — 사이트에 게시하지 않음)

이 파일은 about.html 등 공개 페이지에서 제거한 내용을 보관하는 내부 문서입니다.
sitemap.xml/robots.txt에 포함하지 않고, 어떤 공개 HTML에서도 링크하지 않습니다.

## 운영자 확인이 필요한 질문

- 사업자 형태로 운영 중인지(개인/법인/비사업자) — 사업자라면 상호·대표자명·사업자등록번호·주소를 공개할지
- contact@harukok.com 주소가 실제로 정상 수신되고 있는지, 응답까지 걸리는 기간은 어느 정도인지
- 전문가 검수를 받는지 여부 — 받지 않는다면 "받지 않는다"고 명시할지, 받는다면 어떤 자격의 누구인지
- 이용자 수·후기 등을 공개할 의사가 있는지 (실제 데이터가 없다면 공개 페이지에는 표시하지 않는 것이 원칙)

## 개발/변경 이력 (about.html에서 분리 — 공개 페이지는 운영 목적·범위·검증 기준 중심으로 유지)

### 2026-09-18 정확성 점검

- 연봉 계산기 자녀세액공제: 옛 기준(1명 15만원 등) → 소득세법 제59조의2 기준(1명 25만원·2명 55만원·3명 이상 55만원+40만원×초과인원)으로 수정. 이후 2026.4.21. 개정 부칙(법률 제21548호) 재확인 결과, 2026년 과세기간 자녀세액공제 나이 기준은 9세 이상(2027년 10세, 2028년 11세, 2029년 12세, 2030년부터 13세 이상)이라는 사실을 추가로 확인해, "기본공제대상 자녀 전체"로 잘못 넓혀뒀던 입력 필드를 나이 기준 포함하도록 재수정.
- 퇴직금 계산기: 평균임금 3개월 산정기간의 월말 날짜 밀림 버그 수정(민법 제160조 제3항 — 말일 고정). 이후 재검토에서 "재직일수 365일 이상"으로 지급요건을 판정하던 방식 자체가 윤년 구간에서 틀릴 수 있음을 발견(2024-01-01 입사·2024-12-31 퇴사 재현), 입사일 기준 응당일(만 1년째 되는 날) 도달 여부로 판정하도록 재수정.
- 디데이 계산기: 수능일 11월 13일 고정 표시 및 toISOString 기반 날짜 포맷의 한국 시간대 하루 밀림 버그 수정.
- 32개 페이지의 개발용 광고 슬롯(`data-ad-slot="0000000000"`)·제휴 링크 자리표시자 제거. AdSense 로더·게시자 ID·ads.txt는 유지.
- privacy.html의 "모든 입력이 localStorage에 저장된다"는 부정확한 설명 수정.
- verify/ 디렉터리: 처음에는 계산 로직을 별도 함수로 복사해 테스트했으나(실제 HTML을 읽지 않아 버그를 못 잡는 구조였음), dom-shim.js를 만들어 실제 HTML의 `<script>`를 Node vm에서 그대로 실행해 검증하도록 재작성. 각 verify 스크립트에 "구현을 일부러 깨뜨리면 테스트가 실패하는지" 확인하는 회귀 테스트를 포함.

이 변경 이력은 개발 참고용이며, 공개 소개 페이지(about.html)에는 운영 목적·제공 범위·검증 기준·오류 신고 경로만 남겨뒀습니다.
