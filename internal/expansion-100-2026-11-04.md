# 하루콕 도구 100개 확장 인수인계

기록일: 2026-11-04 (한국 시간). 내부 문서이며 공개 배포 대상이 아닙니다.

## 현재 상태

기존 70개에 신규 30개를 추가해 로컬 소스의 도구를 100개로 확장했습니다. 모든 도구에 기존 격리 광고를 1개씩 연결했습니다. 가이드 목록과 본문 7개를 삭제해 사이트맵은 도구 100개·홈·소개·개인정보 페이지의 총 103개입니다.

**디자인 검사·103개 페이지 빌드·전체 `verify/verify-*.js` 39개를 통과했습니다. 모바일 390px·데스크톱 1280px에서 신규 30개 실행 검사 60건이 통과했고, 독립 브라우저 렌더링 이미지로 입력·결과 화면과 기존 대표 화면을 확인했습니다. 홈의 분류 전환도 두 너비에서 도구 수 일치·카드 겹침 0건·가로 넘침 0건·스크립트 오류 0건으로 확인했습니다.**

기존 Windows 창 캡처는 주소 인식 오류로 중단되어 사용자 프로필과 분리한 테스트 전용 브라우저 렌더링으로 화면을 검토했습니다. 저장된 이미지 일부는 입력 또는 파일 로드 화면이며, 모든 이미지가 최종 결과를 표시한다는 뜻은 아닙니다. 실제 계산·변환 결과는 별도의 60건 실행 기록으로 대조했습니다. 이 기록은 커밋 전 작성했으며, 최종 운영 반영 증거는 Git에서 제외된 `internal/private/production-verification-100-20261104.json`에서 확인합니다.

사용자는 모바일·데스크톱 화면을 확인하고 문제가 없으면 커밋·푸시·운영 배포까지 진행하도록 명시적으로 승인했습니다. 직접 화면 확인을 완료하기 전에는 이번 작업을 배포 완료로 기록하지 않습니다.

## 화면과 탐색 변경

- 홈 카드의 실제 높이로 CSS grid 행 크기를 계산해 큰 빈 공간을 줄였습니다. 글꼴 로드·화면 크기·분류 변경에도 배치를 다시 맞춥니다. 가이드 구역을 제거하고 홈 하단의 정렬을 정리했습니다.
- 별도 예시 실행 버튼을 삭제하고 입력 예시는 placeholder에 표시했습니다. 입력칸 이름은 유지했습니다.
- 반복 안내를 줄이고 기존의 긴 설명·FAQ는 기본으로 접어 두었습니다. 계산 결과에 영향을 주는 제한·가정은 필요한 위치에 남겼습니다.
- 가이드 메뉴·본문·사이트맵 링크를 삭제했습니다. 기존 가이드 주소는 대응하는 도구 또는 홈으로 301 연결해 남아 있는 외부 링크가 도구로 이어지게 했습니다.
- 신규 페이지마다 실제 기능을 설명하는 제목·메타·canonical·구조화 데이터와 관련 도구 링크를 넣었습니다. 검색 순위나 유입 증가를 측정했다는 뜻은 아닙니다.

## 광고와 구현 범위

모든 도구 100개에 `/ad-banner-isolated.js?v=20261027-banner`를 정확히 1개씩 사용합니다. 광고 업체·계정을 추가하지 않았습니다. 공통 스타일은 `/tools/site-ui.css?v=20261104-simple`을 마지막으로 불러옵니다. 새 라이브러리는 추가하지 않았습니다.

긴 정수의 과학적 표기·순열·조합·분수는 문자열 또는 BigInt로 처리합니다. 시간대 변환의 입력은 고정 UTC 또는 UTC+09:00이며 출력은 브라우저의 시간대 자료를 사용합니다. JWT는 내용 해독만 하며 서명을 검증하지 않습니다. SVG 변환은 기본 정적 도형만 지원하고 외부 참조·스크립트·스타일·엔티티를 거부합니다.

## 남은 검증과 배포

1. 전체 검증 스크립트 39개는 모두 통과했습니다.
2. 모바일 390px·데스크톱의 홈·기존 대표 도구·신규 30개 화면과 입력 결과를 확인했습니다. 삭제한 가이드 메뉴·하단 정렬·예시 버튼 제거도 확인했습니다. 복사·이미지 저장의 자동 검증과 실제 브라우저 결과 생성 검증은 구분하며 Windows 클립보드·파일 다운로드를 직접 조작해 확인했다고 기록하지 않습니다.
3. 검증 완료 후 `dev` 커밋·푸시와 미리보기 배포를 확인하고, 동일 커밋을 `main`에 반영합니다.
4. 운영 배포 성공과 103개 페이지·100개 광고·가이드 301·비공개 파일 제외를 확인하고 `internal/private/`에 최종 증거를 남깁니다.

브라우저 QA 입력 목록은 Git에서 제외된 `internal/private/dev100-qa.json`, `math100-qa.json`, `creative100-qa.json`에 있습니다. 내부 문서·검증·개발 스크립트는 `dist/`에 포함하지 않습니다. 자동 반복 작업은 만들지 않았습니다.
