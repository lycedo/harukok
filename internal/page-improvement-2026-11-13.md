# 검색 유입을 위한 페이지 개선 — 2026-11-13

비공개 작업 문서입니다(배포 대상 아님). 사용자가 "사람이 많이 오도록 페이지 전체를 개선해 달라"고 요청해 진행했습니다.
[도구 정리 목록](tool-triage-2026-11-10.md)으로 155개까지 줄인 상태에서 이어집니다.

## 왜 이 순서로 했나

Search Console 기준(2026-08-30 ~ 11-08) 클릭 89회, 노출 772회, 평균 게재순위 29.4위입니다.
순위가 낮아 노출 자체가 적은 상태이므로, 새 기능보다 **검색 결과에 뜨는 글(제목·설명)과 페이지가 담은 내용**을 먼저 손봤습니다.

## 고친 것

### 1. 제목 — 119개

기존에는 88개 페이지의 제목이 `{도구 이름} | 하루콕` 뿐이라 검색어가 들어 있지 않았습니다.
`PDF 분할 - 페이지 나누기·추출·삭제·회전`처럼 실제로 검색하는 말을 앞에 넣었습니다.
155개 모두 제목이 서로 다르고, 70자를 넘지 않습니다.

### 2. 검색 설명 — 119개

23개 페이지에는 기계로 만든 문장이 그대로 남아 있었습니다(예: "서명 명부 만들기로 실제 참석자·구분·행사정보로 서명칸 있는 명부 생성하세요").
읽히는 한국어로 다시 썼고, 통합된 도구는 대표 기능 하나가 아니라 **실제로 할 수 있는 일 전체**를 설명하도록 바꿨습니다.

### 3. 사용방법 한 줄 — 119개

757개 페이지가 "입력 후 실행하세요." 같은 문구 6종 중 하나를 쓰고 있었습니다.
남은 155개에 대해 그 도구에서 실제로 할 일(`달린 거리와 걸린 시간을 넣고 계산하기를 누르세요.`)로 바꿨습니다.

### 4. 통합 도구의 기능 목록 — 85개

통합 도구는 안에 어떤 기능이 들어 있는지 페이지에 드러나지 않았습니다.
본문에 `…에 들어 있는 기능 N가지` 블록을 넣어 기능 이름을 링크로 나열했습니다(10개를 넘으면 접어 둠).
링크를 누르면 새로 고침 없이 같은 자리에서 그 기능으로 바뀝니다. 검색엔진에는 기능 이름이 글로 읽힙니다.

### 5. 관련 도구 — 155개

대부분 1~2개뿐이었고, 분류만 보고 고르면 PDF 분할 페이지에 URL 인코더가 추천되는 문제가 있었습니다.
**같은 계열(슬러그 앞머리) → 검색 노출 순**으로 5개씩 다시 골랐습니다.
인코딩 도구 2개(`url-encoder`, `base64-converter`)는 분류를 PDF·파일에서 개발·데이터로 옮겼습니다.

### 6. 홈 화면

- 로고 아래에 사이트를 설명하는 한 문장을 넣었습니다. 이전에는 홈에 사이트를 설명하는 글이 한 줄도 없었습니다.
- 자주 찾는 도구를 2개에서 6개로 늘리고, 실제 검색 유입이 있는 페이지(로또·상장)와 수요가 큰 작업(연봉·사진 크기·PDF 합치기·퍼센트)으로 채웠습니다.
- 목록 아래에 "하루콕은 어떤 곳인가요?" 안내를 넣었습니다. 파일을 서버로 보내지 않는다는 점, 급여·세금 계산은 예상값이라는 점을 밝힙니다.

### 7. 로또 페이지

검색 클릭의 62%가 이 페이지이고 대표 검색어 순위가 18.4위라 따로 손봤습니다.

- 도움말 블록에 관련 링크만 들어 있던 것을 **자주 묻는 질문 6개**로 채웠습니다(번호를 뽑는 방식, 확률이 올라가지 않는다는 점, 제외 번호, 기록 보관, 공유 링크, 실제 복권과 무관함).
- FAQ 구조화 데이터(FAQPage)를 추가했습니다. 검색 결과에 질문이 함께 뜰 수 있습니다.

## 바로잡은 잘못

`text-file-encoding-converter`를 11-10 정리 때 **"한글 깨짐 복구(인코딩 변환)"**로 이름 붙였는데, 이 도구는 UTF-8과 UTF-16만 지원합니다.
한국에서 한글이 깨지는 원인은 대개 EUC-KR·CP949이므로 이 이름은 할 수 없는 일을 할 수 있다고 말하는 셈이었습니다.
**"텍스트 파일 인코딩 변환"**으로 되돌렸습니다. EUC-KR 지원은 추가하지 않았습니다.

## 검사 보강

`scripts/check-seo.js`의 "홈 전체 도구 목록에 링크 누락" 검사가 홈 어디에든 링크가 있으면 통과하던 것을, **전체 도구 목록 안**에 있어야 통과하도록 좁혔습니다.
홈에 인기 도구 카드가 생기면서 카드가 목록 누락을 가릴 수 있었기 때문입니다. `verify/verify-seo.js`의 해당 변형 테스트도 같이 고쳤습니다.
