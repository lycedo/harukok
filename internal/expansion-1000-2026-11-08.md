## 실제 파일 처리와 한계

새 파일 도구는 사용자의 브라우저에서 실제 결과 파일을 만듭니다. 입력 파일·문서·인증 비밀값을 서버에 업로드하거나 새 저장소에 보관하지 않습니다. 광고·폰트·라이브러리 같은 페이지 자산 요청은 파일 내용 처리와 별개입니다. 원본 파일은 보존하고 사용자가 결과를 내려받습니다.

공통 파일 입력 한도는 파일당 20MB·전체 50MB이며 출력은 전체 100MB입니다. 각 도구의 더 작은 개수·페이지·픽셀·셀 제한도 적용합니다. 압축 해제와 파일 나누기는 결과 200개까지입니다. ZIP은 암호화·ZIP64·분할·위험 경로를 거부하고, 압축을 풀기 전에 실제 DEFLATE 출력 크기를 검사합니다. TAR는 일반 USTAR 파일·폴더만 지원합니다.

PDF는 암호화된 입력·서명 문서의 편집·XFA를 지원하지 않습니다. 일반 입력·출력 페이지는 200쪽 이내입니다. PDF 글자 추출은 OCR이 아니며, 자르기는 화면 영역 변경으로서 민감정보 삭제를 뜻하지 않습니다. PDF.js 렌더링 도구에는 별도의 페이지·픽셀 한도가 있습니다.

XLSX는 수식을 계산하지 않고 마지막 저장 결과를 사용합니다. 캐시가 없는 수식은 오류로 알립니다. CSV→XLSX는 앞자리 0과 수식처럼 보이는 글자를 텍스트 셀로 보존합니다. 외부 통합문서를 가리키는 이름 정의가 있는 파일은 Excel 이름 관리자에서 먼저 정리하도록 안내합니다. DOCX 작성자 삭제는 문서 속성만 대상으로 하며 본문·메모·변경 기록까지 익명화한다고 주장하지 않습니다.
