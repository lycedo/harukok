로또 번호 생성기

1~45 중 무작위 6개, 클릭 한 번이면 끝.

최근 생성 기록

번호는 어떻게 만들어지나요?

브라우저의 난수 생성 기능(Math.random)을 이용해 1~45 사이 숫자 중 중복 없이 6개를 뽑습니다. 실제 로또 추첨기처럼 모든 번호가 동일한 확률로 나오도록 설계되어 있고, 서버로 전송되는 데이터 없이 기기 안에서 즉시 계산됩니다.

당첨 확률이 더 높아지나요?
아닙니다. 어떤 방식으로 번호를 골라도 당첨 확률은 동일합니다. 이 도구는 번호를 고민하는 시간을 줄여주는 용도로만 사용해주세요.
같은 번호가 또 나올 수 있나요?
네, 매번 완전히 새로 뽑기 때문에 이전과 같은 조합이 다시 나올 수도 있습니다. 통계적으로는 지극히 낮은 확률입니다.
여러 게임을 한번에 만들 수 없나요?
한 번 클릭에 한 게임씩, 최근 뽑기 기록에 최대 30개까지 자동으로 쌓입니다. 필요한 만큼 여러 번 눌러서 기록에서 확인하세요.
