자주 묻는 질문

어떤 마크다운 문법까지 변환되나요?

제목 기호 한 개에서 여섯 개까지, 하이픈·별표·더하기 글머리 목록, 인용 기호, 백틱 세 개로 감싼 코드 블록, 인라인 코드, 굵게와 기울임, 대괄호 링크를 처리합니다. 표와 각주, 목록 안의 목록은 바뀌지 않습니다.

줄바꿈만 하면 문단이 나뉘나요?

빈 줄이 아닌 줄은 각각 하나의 문단이 됩니다. 한 문단을 여러 줄로 끊어 써 두면 결과에서도 여러 문단으로 갈라지니, 이어 붙이고 싶다면 한 줄로 모아 주세요.

링크 주소가 형식에 안 맞으면 어떻게 되나요?

http·https·mailto·tel 주소만 링크로 만듭니다. 그 밖의 값이면 링크를 걸지 않고 글자 뒤에 괄호로 주소를 적어 둡니다. 코드 블록을 닫지 않으면 변환을 멈추고 알려 줍니다.

HTML 태그를 그대로 섞어 써도 되나요?

원본에 적은 태그 기호는 모두 일반 글자로 바꿔 화면에 그대로 보여 줍니다. 결과는 언어가 한국어로 지정된 완전한 HTML 문서 한 장이며, 미리보기로 모양을 확인하고 HTML 저장이나 인쇄·PDF 저장으로 받습니다.

목차나 링크 문법만 만들 수도 있나요?

마크다운 제목 목차 추출은 본문 제목만 모아 단계마다 두 칸씩 들여쓴 목록으로 돌려주고 코드 블록 안의 기호는 건너뜁니다. 마크다운 링크 만들기는 이름과 URL을 탭으로 나눈 줄을 받아 대괄호 링크로 바꿔 줍니다.
