JSON 형식을 검사하고 읽기 쉽게 정리하세요

설정 파일이나 API 응답의 괄호 구조를 살펴볼 때 쓸 수 있습니다. 문법을 확인한 뒤 문자열 밖의 공백만 바꾸며 원문 입력은 덮어쓰지 않습니다.

큰 숫자와 키 순서는 그대로인가요?

예를 들어 {"번호":9007199254740993,"비율":1.00}을 정리해도 9007199254740993과 1.00 표기를 그대로 남깁니다. JSON을 자바스크립트 객체로 바꾼 결과를 다시 출력하지 않고 원문의 각 숫자·문자열 조각을 사용합니다.

키 순서, 중복 키, 문자열의 이스케이프 표기도 유지합니다. 중복 키를 없애거나 숫자를 반올림하지 않습니다. 중복 키가 있는 자료는 이를 읽는 프로그램마다 처리에 주의해야 합니다. 정리 결과는 데이터 구조나 필수 필드가 올바른지까지 확인하는 검사가 아닙니다.

JSON 문법 오류가 나면 무엇을 확인하나요?

키와 글자는 큰따옴표로 감싸고, 마지막 항목 뒤의 쉼표는 지우세요. 작은따옴표, 주석, undefined는 JSON 문법이 아닙니다. 오류가 있으면 결과를 만들지 않으며 원문을 직접 수정한 뒤 다시 실행할 수 있습니다.

객체와 배열뿐 아니라 숫자·문자열·true·false·null만 있는 JSON도 검사합니다. 형식 검사는 브라우저의 JSON 문법 검사 기준을 따릅니다.

한 줄 압축과 들여쓰기의 차이는 무엇인가요?

들여쓰기는 괄호 안의 항목을 새 줄에 배치하고 2칸 또는 4칸으로 깊이를 표시합니다. 빈 객체와 배열은 {}와 []로 남깁니다. 한 줄 압축은 문자열 밖의 불필요한 공백만 없애며 문자열 안의 띄어쓰기는 유지합니다.

입력은 최대 200,000자, 괄호 중첩은 100단계, 출력은 2,000,000자까지 처리합니다. 글자 길이는 브라우저 기준이므로 이모지는 두 자리 이상으로 셀 수 있습니다. 입력 내용은 서버로 보내거나 저장하지 않습니다.
