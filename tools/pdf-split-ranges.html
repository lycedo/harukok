자주 묻는 질문

나눌 범위는 어떤 식으로 적나요?

한 줄에 한 묶음씩 적습니다. 1-2처럼 범위를, 3처럼 한 장을 적을 수 있고 1-3,5처럼 쉼표로 이어도 됩니다. 최대 30줄까지 받고 줄마다 part-1.pdf, part-2.pdf 순으로 따로 저장됩니다.

한 줄 안에 같은 페이지를 두 번 적어도 되나요?

나누기·추출·삭제에서는 같은 번호가 겹치면 중복이라고 알려 줍니다. 같은 페이지를 여러 번 쓰고 싶을 때는 순서 바꾸기 기능을 쓰면 3,1,2처럼 번호를 겹쳐 적어 복제할 수 있습니다.

필요한 페이지만 남기거나 지우려면 어떻게 하나요?

페이지 추출은 적은 번호만 모아 새 PDF를 만들고, 칸을 비우면 전체가 됩니다. 페이지 삭제는 적은 번호를 빼고 나머지를 남기며 전부 지우려 하면 최소 한 장은 남기라고 막습니다.

방향이 틀어진 쪽만 돌릴 수 있나요?

회전 기능에서 90도·180도·270도 중 시계 방향 각도를 고르고 돌릴 페이지만 적으면 됩니다. 비우면 전체가 돌아가고, 각도는 지금 저장된 회전값에 더해지므로 이미 돌아간 쪽은 그만큼 더 돌아갑니다.

입력 양식이 들어 있는 PDF도 되나요?

양식이 남아 있으면 먼저 양식 고정으로 글자로 굳히라고 안내합니다. 전자서명이 있는 파일은 편집하지 않고, 파일은 한 개 20MB·1쪽에서 200쪽까지, 결과 합계는 100MB까지 브라우저 안에서만 처리합니다.
