자주 묻는 질문

Word 파일이 서버로 올라가나요?

올라가지 않습니다. 고른 파일은 브라우저가 직접 열어 압축을 풀고 글자를 뽑으며, 결과 파일도 브라우저 안에서 만들어 내려받습니다. 원본 파일은 그대로 남습니다.

어떤 내용이 텍스트로 나오나요?

docx 안 본문 문단을 순서대로 모아 word-text.txt로 저장합니다. 표 안에 든 문단도 함께 들어오고 탭과 줄바꿈은 살리지만, 글꼴·색·크기 같은 서식은 남지 않습니다.

파일 크기나 개수 제한이 있나요?

파일 하나는 20MB까지, 고른 파일 전체는 50MB까지입니다. 꺼낸 결과는 최대 200개 파일, 합계 100MB까지이며 Word 텍스트 추출은 한 번에 한 파일만 받습니다.

매크로나 암호가 걸린 문서도 되나요?

매크로가 들어 있는 문서는 vbaProject 파일이 발견되면 처리하지 않고 멈춥니다. 암호로 암호화된 파일, ZIP64와 분할 압축 형식도 지원하지 않으니 보호를 풀고 다시 저장해 주세요.

사진이나 PowerPoint도 꺼낼 수 있나요?

기능 선택에서 Word 사진 추출을 고르면 문서 안 media 폴더의 그림을 원래 파일 이름으로 하나씩 내려받습니다. PowerPoint는 슬라이드 순서대로 번호를 붙여 텍스트를 뽑거나 사진만 꺼낼 수 있습니다.
