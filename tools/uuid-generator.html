UUID v4 생성기 사용 안내

테스트 자료의 식별자나 임시 레코드 키가 필요할 때 사용할 수 있습니다. 16바이트 난수에 UUID v4의 버전·variant 비트를 적용하고 표준 하이픈 형식으로 표시합니다.

어떤 형식의 UUID를 만드나요?

8-4-4-4-12자리의 소문자 16진수 형식입니다. 세 번째 묶음은 4로 시작하고, 네 번째 묶음은 8·9·a·b 중 하나로 시작하는 UUID v4입니다. 시간 순서로 정렬되는 UUID v7은 지원하지 않습니다.

매번 다르고 절대 겹치지 않나요?

브라우저의 Web Crypto 난수를 이용하며 같은 실행에서 중복된 UUID는 다시 만듭니다. 다른 실행이나 다른 시스템의 UUID와 절대로 충돌하지 않는다고 보장하지는 않습니다. 데이터베이스에서 키로 쓰면 저장할 때 고유성도 확인하세요.

이전 UUID를 복구할 수 있나요?

이 도구는 결과를 서버나 브라우저 기록에 저장하지 않습니다. 생성 뒤 필요한 곳에 복사해 두세요. 개수를 바꾸면 이전 결과를 숨기고 다시 생성해야 합니다. UUID는 비밀번호 생성기나 암호 키 생성기를 대신하지 않습니다.
