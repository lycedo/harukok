글자와 배경이 충분히 구분되나요?

밝기 차이를 숫자로 확인합니다. 검정과 흰색은 21:1, 같은 색끼리는 1:1입니다. 이 결과는 텍스트 색상 대비의 계산이며 사이트 전체의 접근성 평가가 아닙니다.

AA와 AAA는 어떤 기준인가요?

일반 글자는 AA 4.5:1, AAA 7:1 이상입니다. 큰 글자는 AA 3:1, AAA 4.5:1 이상입니다. 큰 글자는 18pt(24 CSS px) 이상이거나 굵은 14pt(약 18.67 CSS px) 이상인 텍스트를 뜻합니다.

4.50:1로 보여도 미달일 수 있나요?

표시는 소수점 둘째 자리로 반올림하지만 판정은 반올림 전 실제 값으로 합니다. 4.499:1은 표시가 4.50이어도 4.5보다 작으므로 일반 글자 AA에 미달합니다.

사진이나 투명 배경도 검사하나요?

아니요. 불투명 단색 두 개만 계산합니다. 사진이나 그라데이션 위 글자는 여러 위치의 배경을 따로 확인해야 합니다. 입력값을 서버에 보내거나 저장하지 않습니다.
