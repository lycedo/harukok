정해진 범위에서 정수를 뽑으세요

수업 번호나 게임 순서를 정할 때 쓸 수 있습니다. 결과는 뽑힌 순서로 표시하며 크기순으로 다시 정렬하지 않습니다.

1부터 5까지 5개를 뽑으면?

중복을 허용하지 않으면 1·2·3·4·5가 각각 한 번씩 무작위 순서로 나옵니다. 같은 범위에서 6개를 중복 없이 뽑을 수는 없습니다. 범위를 넓히거나 개수를 줄이세요.

최솟값과 최댓값이 같아도 되나요?

두 값이 7이면 뽑을 수 있는 수는 7 하나입니다. 중복 없이 한 개를 뽑거나 중복 허용을 켜 여러 개의 7을 만들 수 있습니다. -5부터 5처럼 음수가 포함된 범위도 지원합니다.

숫자마다 기회가 같나요?

Web Crypto 난수를 사용하고 범위로 나눌 때 생길 수 있는 편향을 피하기 위해 일부 난수를 다시 뽑습니다. 중복 허용이면 각 추첨에서 같은 숫자가 다시 나올 수 있고, 허용하지 않으면 남은 숫자 안에서 뽑습니다. 결과는 자동 저장하지 않습니다.
