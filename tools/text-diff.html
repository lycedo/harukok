글을 고친 뒤 바뀐 줄을 확인하세요

문서 초안이나 목록을 수정한 뒤 어떤 줄이 바뀌었는지 살펴볼 때 쓸 수 있습니다. 원문 입력칸은 그대로 두고 비교 결과만 따로 만듭니다.

비교 결과는 어떻게 읽나요?

이전 글의 ‘사과 / 바나나 / 포도’와 새 글의 ‘사과 / 딸기 / 포도’를 줄마다 넣으면 사과와 포도는 동일, 바나나는 삭제, 딸기는 추가로 표시됩니다. 각 줄 옆에는 이전 글과 새 글에서의 줄 번호가 나옵니다.

한 줄에서 한 글자만 바뀌어도 이전 줄의 삭제와 새 줄의 추가로 표시합니다. 글자 단위 강조나 맞춤법 검사는 하지 않습니다. 위치를 옮긴 줄도 삭제·추가로 보일 수 있습니다.

공백과 빈 줄도 차이로 보나요?

앞뒤 공백, 띄어쓰기, 대소문자를 구별하고 줄 전체를 비교합니다. 빈 줄도 하나의 줄이며 마지막 줄바꿈 뒤의 빈 줄도 셉니다. 윈도우식 CRLF와 CR 줄바꿈은 LF로 맞춰 비교하므로 줄바꿈 형식만 다른 경우는 동일하게 봅니다.

같은 줄이 여러 번 있으면 앞뒤 순서를 유지하며 가장 많이 일치하는 줄 묶음을 기준으로 비교합니다. 가능한 결과가 여러 개면 삭제를 먼저 표시합니다. 입력 한도는 브라우저 글자 길이 기준으로 이모지는 두 자리 이상으로 셀 수 있습니다.

한쪽 글이 비어 있어도 비교할 수 있나요?

한쪽만 비어 있으면 다른 쪽의 모든 줄을 삭제 또는 추가로 표시합니다. 두 칸이 모두 비어 있으면 비교하지 않습니다. 결과는 브라우저 안에서 만들며 서버에 보내거나 저장하지 않습니다. 복사 버튼을 누르면 결과가 기기의 클립보드로 전달됩니다.
