CSV·JSON 변환기 사용 안내

쉼표가 들어간 셀, 큰따옴표, 셀 안 줄바꿈을 구별해 표를 변환합니다. 숫자처럼 보이는 값도 문자열로 유지하므로 앞의 0과 긴 번호를 그대로 옮길 수 있습니다.

CSV의 큰따옴표는 어떻게 적나요?

쉼표·큰따옴표·줄바꿈이 들어간 셀은 큰따옴표로 감쌉니다. 셀 안 큰따옴표는 두 번 적습니다. 예를 들어 "쉼표, 큰따옴표 ""예시"""는 하나의 셀입니다. 줄바꿈은 LF·CRLF·CR을 읽고 CSV 결과는 CRLF로 만듭니다. 셀 안 줄바꿈은 보존합니다.

JSON은 어떤 모양이어야 하나요?

[{"이름":"하루콕","번호":"001"}]처럼 열 이름이 같은 객체 배열이나, [["이름","번호"],["하루콕","001"]]처럼 첫 행에 열 이름이 있는 행 배열을 지원합니다. 셀 값은 문자열만 허용하며 숫자·null·객체·배열 셀은 거절합니다.

열 이름이 겹치거나 행마다 열 수가 다르면?

빈 열 이름·중복 열 이름·중복 JSON 키는 거절합니다. 모든 행의 열 수 또는 객체의 키를 맞춰야 합니다. 열 이름과 셀의 앞뒤 공백은 자동으로 지우지 않습니다. 객체 배열은 머리글 한 행을 추가하므로 999개 객체까지 지원합니다. 머리글만 있는 CSV는 []로 변환되며, 빈 JSON 배열은 열 이름을 알 수 없어 CSV로 변환하지 않습니다. CSV를 여는 프로그램의 셀 표시 형식은 별도로 확인하세요.
