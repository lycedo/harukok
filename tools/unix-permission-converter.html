chmod 권한 변환기

기능 선택

사용방법 숫자나 기호 권한을 넣으면 바로 변환됩니다.

브라우저에서 처리합니다. 서버 전송 없음.

결과

chmod 권한 변환기에 들어 있는 기능 2가지

위의 기능 선택에서 고르면 같은 자리에서 바로 바뀝니다. 파일과 입력값은 이 브라우저 안에서만 처리합니다.

자주 묻는 질문

755를 넣으면 무엇이 나오나요?

8진수 → 기호 방향에서 rwxr-xr-x가 나옵니다. 세 자리나 네 자리 8진수를 받아 소유자·그룹·기타 순으로 r·w·x 아홉 글자를 만들며, 644는 rw-r--r--가 됩니다.

setuid나 sticky bit도 변환되나요?

네 자리 8진수의 맨 앞자리를 읽습니다. 4000은 소유자 실행 자리에 s, 2000은 그룹 자리에 s, 1000은 기타 자리에 t로 찍고, 실행 권한이 없는 상태면 대문자 S와 T로 구분해 표시합니다.

앞에 파일 종류 글자가 붙은 권한도 넣을 수 있나요?

기호 → 8진수 방향은 파일 종류를 뜻하는 맨 앞 글자를 떼고 권한 아홉 글자만 받습니다. 결과는 특수 비트 자리를 포함해 0755처럼 네 자리로 돌려줍니다.

umask 022는 어떤 권한이 되나요?

umask 권한 계산기 기능으로 바꾸면 세 자리 8진수를 받아 일반 파일 644, 디렉터리 755를 알려 줍니다. 파일은 0666, 디렉터리는 0777에서 umask 비트를 뺀 값이라 파일에는 실행 권한이 처음부터 붙지 않습니다.

형식이 틀리면 어떻게 되나요?

8진수는 0부터 7까지의 숫자 세 자리나 네 자리, 기호는 정해진 순서의 아홉 글자만 통과합니다. 조건을 벗어나면 변환하지 않고 어떤 형식이 필요한지 알려 주며, 계산은 브라우저 안에서 끝납니다.
