PostgreSQL 문자열 문법

자주 묻는 질문

표는 어떤 구분자로 붙여 넣어야 하나요?

탭으로 나뉜 표를 받습니다. 엑셀이나 구글 시트에서 범위를 복사해 그대로 붙이면 됩니다. 첫 줄이 열 이름이고 머리글까지 합쳐 200행·30열까지, 모든 줄의 열 수가 같아야 합니다.

값에 따옴표나 줄바꿈이 있으면 깨지지 않나요?

모든 값을 PostgreSQL의 E 접두사 문자열로 감싸고 홑따옴표는 두 번 적으며 역슬래시는 겹쳐 적습니다. 제어문자는 16진수 이스케이프로 바꾸고, NUL 문자가 섞여 있으면 만들기를 멈춥니다.

숫자나 NULL을 알아서 구분해 주나요?

구분하지 않습니다. 빈 칸까지 모두 문자열로 내보내므로 숫자 열이나 NULL이 필요하면 만들어진 문장을 직접 손봐야 합니다. 열 이름과 테이블 이름은 쌍따옴표로 묶어 그대로 씁니다.

테이블 이름은 어떻게 적나요?

users처럼 이름만 적거나 public.users처럼 스키마를 함께 적습니다. 점은 한 번까지만 허용하고 각 조각은 제어문자 없이 1에서 63바이트여야 합니다. 양끝 공백은 떼고 처리합니다.

IN절이나 UPDATE문도 만들 수 있나요?

위쪽 기능 선택에서 SQL IN절 만들기와 CSV SQL UPDATE 만들기로 바꿀 수 있습니다. IN절은 줄 단위 값 목록을 받아 중복을 남기거나 지울 수 있고, UPDATE는 CSV에서 키 열을 지정해 행마다 한 문장을 만듭니다.
