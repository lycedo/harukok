정규식 테스트 도구 사용 안내

문자열에서 원하는 부분을 찾는 패턴을 확인합니다. 검사 결과를 HTML로 실행하지 않고 글자로 표시하며, 정규식 실행은 화면과 분리한 Worker에서 처리합니다.

패턴과 옵션은 어떻게 넣나요?

/hello/gi라면 패턴에는 hello, 옵션에는 gi를 넣습니다. g를 빼면 첫 번째 일치만 찾습니다. 예시 (하루)(콕)은 하루콕 전체와 괄호로 나눈 두 그룹을 보여줍니다. 브라우저의 JavaScript 정규식 문법을 사용하므로 다른 언어의 결과와 다를 수 있습니다.

위치 번호와 빈 일치는 무엇인가요?

위치는 0부터 시작하는 UTF-16 코드 단위 기준입니다. 이모지는 두 자리로 셀 수 있습니다. 빈 패턴처럼 길이 0인 부분이 일치할 때도 다음 위치로 이동하여 무한 반복을 막습니다. u 옵션은 유니코드 글자 경계를 반영합니다.

검사가 시간 초과되거나 결과가 잘리면?

Worker 시작·실행·응답이 0.75초를 넘으면 중단합니다. 결과가 200개를 넘으면 처음 200개만 표시합니다. 복잡한 패턴이나 긴 글은 작게 나누어 검사하세요. 실행 시간은 기기 상태에 영향을 받으며 처리 시간 제한이 실제 서비스에서의 정규식 성능을 보장하지는 않습니다.
