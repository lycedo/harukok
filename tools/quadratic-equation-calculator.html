이차방정식 계산기

사용방법 ax² + bx + c = 0의 a·b·c를 넣고 계산하세요.

계수는 -10억~10억 · 0도 입력하세요. 실근은 최대 12자리 유효숫자의 근삿값입니다.

판별식으로 실근의 개수를 구분합니다

a가 0이 아니면 판별식 D = b² − 4ac를 계산합니다. 양수이면 서로 다른 두 실근, 0이면 중근, 음수이면 실수 범위의 해가 없습니다.

x² − 3x + 2 = 0을 풀려면?

a = 1, b = -3, c = 2를 넣으세요. 판별식은 1이고 두 실근은 x = 1과 x = 2입니다. x² + 2x + 1 = 0은 판별식이 0이며 중근 x = -1입니다.

a가 0이거나 모든 계수가 0이면?

a = 0, b가 0이 아니면 bx + c = 0의 일차방정식으로 계산합니다. a와 b가 모두 0이면 c도 0일 때 모든 실수가 해이고, c가 0이 아니면 해가 없습니다. 0인 칸도 비워 두지 말고 0을 입력하세요.

실근이 없다는 말은 복소수 해도 없다는 뜻인가요?

아닙니다. a가 0이 아닌 이차방정식의 판별식이 음수이면 복소수 해가 있지만 이 도구는 실근만 표시합니다. 실수 연산과 반올림을 사용하므로 아주 가까운 근이나 크기 차이가 큰 계수에서 근삿값의 한계가 있습니다. 계산 범위를 벗어나면 오류를 안내합니다.
