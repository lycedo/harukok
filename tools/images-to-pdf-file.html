공개 라이브러리 고지
자주 묻는 질문

사진 여러 장을 묶을 때 페이지 순서는 어떻게 정하나요?

파일을 고른 순서가 그대로 페이지 순서가 됩니다. 선택하면 1. 2. 처럼 번호를 붙인 파일 목록과 전체 바이트 수가 표시되니, 순서가 다르면 다시 고르면 됩니다.

페이지 크기는 무엇을 고르면 되나요?

이미지 비율은 사진 한 변을 0.75배 한 크기로 페이지를 만들어 여백 없이 채웁니다. A4는 595.28 × 841.89포인트 페이지에 비율을 지켜 줄인 뒤 가운데에 놓습니다.

어떤 형식의 사진을 넣을 수 있나요?

PNG·JPEG·WebP·BMP를 받습니다. 파일 하나는 20MB, 전체 50MB, 최대 100개까지이며 사진 한 장은 1600만 화소·한 변 16000px, 모두 합쳐 3200만 화소까지입니다.

사진이 서버로 올라가나요?

올라가지 않습니다. PDF 조립은 같은 사이트에서 함께 내려받는 pdf-lib 1.17.1이 브라우저 안에서 수행하고, 완성된 결과는 images.pdf 저장 버튼으로 받습니다.

사진에 들어 있던 촬영·위치 정보도 PDF에 따라가나요?

각 사진은 PDF에 넣기 전에 PNG로 다시 만들어지므로 원본의 촬영 시각이나 위치 정보는 옮겨지지 않습니다. 결과 PDF에는 화면에 보이는 그림만 담깁니다.
