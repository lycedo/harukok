한글과 특수문자를 URL 값으로 바꾸세요

주소의 검색어 값처럼 URL의 한 부분에 글을 넣을 때 사용할 수 있습니다. 글을 인코딩하고, 퍼센트 표기로 전달받은 값을 디코딩해 내용을 확인하세요.

변환 예시와 적용 범위는 무엇인가요?

인코딩에서 ‘가 나’를 넣으면 %EA%B0%80%20%EB%82%98가 됩니다. 공백은 %20, &는 %26, +는 %2B로 바뀝니다. 디코딩은 이 표기를 다시 원래 글로 되돌립니다.

encodeURIComponent와 decodeURIComponent를 사용합니다. URL 전체를 보존하는 encodeURI 방식은 아닙니다. https://로 시작하는 전체 주소를 넣으면 :와 /까지 인코딩되므로 필요한 값 부분만 넣으세요. 암호화 기능이 아니며 내용을 숨기는 용도로 사용할 수 없습니다.

+ 기호는 왜 공백으로 바뀌지 않나요?

이 도구는 +를 일반 글자로 처리합니다. 디코딩에서 A+B는 그대로 A+B이고 A%20B는 A B가 됩니다. 웹 폼의 application/x-www-form-urlencoded 방식처럼 +를 공백으로 해석하지 않습니다.

디코딩 오류가 나거나 두 번 인코딩된 값이면?

% 뒤에는 0~9 또는 A~F로 된 두 자리가 필요하며, 그 조합이 올바른 UTF-8 글자를 나타내야 합니다. 잘린 % 표기나 잘못된 문자 조합은 결과를 만들지 않습니다. 원문은 남아 있으므로 값을 확인해 다시 넣으세요.

%2520을 한 번 디코딩하면 %20입니다. 한 번의 실행은 한 단계만 변환하므로 필요한 횟수를 직접 확인하세요. 입력 한도는 브라우저 글자 길이 기준으로 이모지는 두 자리 이상으로 셀 수 있습니다. 입력 내용을 서버로 보내거나 저장하지 않습니다.
