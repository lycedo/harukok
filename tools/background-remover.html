흰색 배경 제거

로고·도형·그림의 흰 배경을 투명하게 바꾸세요. 사진 속 사람을 자동으로 구분하는 도구가 아니라, 지정한 범위의 흰색을 지우는 도구입니다.

이미지 선택

JPG·PNG·WebP · 10MB, 1,200만 화소 이하. 긴 변이 1,600px보다 크면 비율을 유지하며 줄입니다. 파일은 서버에 업로드하지 않습니다.

작업할 원본

0은 순수한 흰색만, 20은 RGB 각 값이 235 이상인 색을 지웁니다. 높일수록 밝은 회색도 함께 지워집니다.

투명 PNG 결과

투명 PNG 저장

체크무늬는 미리보기 배경이며 저장되는 PNG에는 포함되지 않습니다. 설정을 바꿨다면 다시 지워야 저장할 수 있습니다.

광고

로고의 흰 배경을 투명하게 만드는 순서

  1. 이미지를 선택하거나 예제로 먼저 결과를 확인합니다.
  2. ‘가장자리와 연결된 흰색만 제거’를 선택한 상태로 흰 배경을 지웁니다.
  3. 흰 테두리가 남으면 흰색 범위를 조금씩 높여 다시 처리합니다.
  4. 원본과 비교해 필요한 부분이 남았는지 확인한 뒤 투명 PNG를 저장합니다.

두 가지 제거 방식의 차이

가장자리 연결 여부에 따른 결과
방식지우는 범위주의할 점
가장자리 연결만이미지 테두리에서 상하좌우로 이어지는 흰 영역닫힌 도형 내부의 흰색은 남습니다.
전체 흰색위치에 관계없이 설정 범위에 맞는 흰색흰 글자·눈·옷 같은 필요한 부분도 지워질 수 있습니다.

예제의 네모 테두리 안에는 흰색이 들어 있습니다. 기본 방식에서는 네모 밖만 투명해지고 안쪽은 남습니다. 체크를 풀고 다시 실행하면 내부 흰색도 투명하게 바뀌는 차이를 볼 수 있습니다.

흰색 범위를 조절하는 기준

순수한 흰색은 RGB 값이 모두 255인 색입니다. 이 도구의 범위가 20이면 빨강·초록·파랑 값이 각각 235 이상인 픽셀을 흰색 후보로 봅니다. 각 값이 모두 기준을 넘어야 하므로 밝더라도 색이 진하게 섞인 영역은 남을 수 있습니다.

JPG는 저장 과정에서 흰 배경에 회색이나 색 번짐이 생길 수 있습니다. 범위를 높이면 이런 부분을 더 지울 수 있지만, 필요한 밝은 부분까지 사라질 수 있습니다. 한 번에 크게 올리기보다 5~10씩 조절하고 결과를 비교하세요.

잘 맞는 이미지와 어려운 이미지

흰 종이 위의 단순한 그림, 배경과 색이 뚜렷이 다른 로고, 단색 도형에 적합합니다. 머리카락, 그림자, 흰 옷, 흰색 제품처럼 배경과 피사체 색이 비슷한 사진에서는 경계를 정확히 구분할 수 없습니다. 경계 픽셀을 부드럽게 복원하거나 숨겨진 색을 추정하는 기능은 없습니다.

출력은 투명도를 지원하는 PNG입니다. 투명도를 유지하려면 이후 편집 과정에서도 PNG나 투명도를 지원하는 형식을 사용하세요. JPG로 바꾸면 투명한 부분을 색으로 채워야 합니다.

자주 묻는 질문

배경을 지웠는데 흰색으로 보이는 이유는 무엇인가요?

일부 사진 앱은 투명한 부분을 흰색으로 보여줍니다. 이 페이지에서 체크무늬가 보이면 해당 부분은 투명합니다. 다른 배경색 위에 올려보면 확인할 수 있습니다.

투명 PNG인데 용량이 더 커졌어요.

PNG는 JPG와 다른 압축 방식을 사용하므로 투명해졌다고 파일 용량이 줄어들지는 않습니다. 이미지 크기·용량 줄이기에서 크기를 줄이거나 투명도를 지원하는 WebP 출력을 비교하세요.

원본 해상도가 그대로 유지되나요?

긴 변이 1,600px 이하인 이미지는 크기를 유지합니다. 더 큰 이미지는 모바일에서 처리할 수 있도록 먼저 줄이며 작업 크기를 화면에 표시합니다. 원본 파일은 바꾸지 않습니다.

사진이나 파일 이름이 서버에 저장되나요?

선택한 파일은 이 페이지 안에서만 읽습니다. 사이트 서버에 보내거나 브라우저 저장소에 남기지 않습니다. 저장 버튼으로 내려받은 결과 파일은 이용자의 기기에 남습니다. 광고 등 외부 서비스의 일반적인 접속 정보 처리는 개인정보처리방침을 참고하세요.

움직이는 이미지도 처리하나요?

애니메이션은 보존하지 않습니다. 움직이는 WebP·PNG를 선택하더라도 정지된 한 장으로 처리됩니다. GIF·SVG·HEIC는 지원하지 않습니다.
