IANA 상태 코드 등록표

자주 묻는 질문

어떤 상태 코드를 조회할 수 있나요?

100에서 599까지의 정수를 넣으면 영문 이름과 분류가 나옵니다. 100번대는 정보 응답, 200번대 성공, 300번대 리디렉션, 400번대 클라이언트 오류, 500번대 서버 오류로 묶어 보여 줍니다.

없는 번호를 넣으면 어떻게 되나요?

범위 안이어도 도구에 담아 둔 목록에 없으면 수록 코드가 아니라는 안내와 분류만 표시됩니다. 418과 306처럼 지금은 쓰이지 않는 번호는 괄호를 쓴 Unused로 나옵니다.

입력한 사이트에 실제로 요청을 보내 확인해 주나요?

아닙니다. 서버에 아무 요청도 하지 않고 페이지 안에 적어 둔 표에서 찾아 보여 줍니다. 최신 정의를 확인하려면 아래 참고에 있는 IANA 상태 코드 등록표 링크를 쓰면 됩니다.

MIME 타입 조회도 같은 페이지에서 되나요?

위쪽 기능 선택에서 파일 확장자 MIME 조회를 고르면 같은 자리에서 열립니다. 확장자를 넣으면 MIME 값을, MIME 값을 넣으면 그에 해당하는 확장자 목록을 되돌려 줍니다.

한 번에 여러 코드를 넣을 수 있나요?

한 번에 한 코드만 받습니다. 정수가 아닌 글자나 소수를 적으면 정수를 입력하라는 오류가 나옵니다. 결과는 404 Not Found 같은 한 줄과 분류 한 줄로 나와 그대로 복사할 수 있습니다.
