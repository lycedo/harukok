자주 묻는 질문

스캔한 PDF에서도 글자가 나오나요?

나오지 않습니다. PDF 안에 이미 글자 정보로 들어 있는 내용만 읽습니다. 종이를 찍은 그림만 담긴 파일은 글자 인식을 하지 않으므로 결과가 비어 있게 됩니다.

추출한 글은 어떤 모양으로 정리되나요?

페이지마다 세 개의 붙임표와 쪽 번호로 된 머리줄이 붙고 그 아래에 해당 쪽의 글이 들어갑니다. 전체는 text.txt 파일로 내려받으며 결과 칸에서 복사해도 됩니다.

특정 페이지만 뽑을 수 있나요?

페이지 칸에 1-3,5처럼 적으면 그 쪽만 처리하고 비워 두면 전체를 처리합니다. 같은 번호를 두 번 쓰거나 실제 쪽 수를 넘는 번호를 쓰면 범위를 확인하라고 알려 줍니다.

암호가 걸린 PDF도 되나요?

암호화된 PDF는 지원하지 않고 안내만 나옵니다. 파일은 하나당 20MB, 합계 50MB, 1~200페이지까지이며 뽑아낸 글자가 100만 자를 넘으면 페이지를 나눠 처리하라고 알려 줍니다.

링크 주소만 따로 모을 수도 있나요?

기능 선택에서 PDF 링크 추출로 바꾸면 쪽 번호와 주소를 담은 links.json을 만들어 줍니다. 링크는 2,000개까지 모으며, 두 기능 모두 파일을 브라우저 안에서만 엽니다.
