자주 묻는 질문

스크립트나 스타일 안의 글자도 섞여 나오나요?

script, style, noscript, template, head, svg, math, object, iframe 안의 내용은 빼고 읽습니다. 그래서 페이지 소스를 통째로 붙여 넣어도 코드가 본문에 섞이지 않습니다.

줄바꿈은 어떻게 처리되나요?

br 태그는 줄바꿈 하나가 되고 p, div, li, 제목 태그, table, tr 같은 덩어리 태그는 앞뒤로 줄을 띕니다. 표 한 행 안의 칸은 탭으로 이어지며 빈 줄이 셋 이상이면 둘로 줄입니다.

nbsp 같은 문자 표기는 글자로 바뀌나요?

바뀝니다. 이름이 붙은 여섯 가지 기본 표기와 십진수·십육진수 코드 표기를 해당 글자로 되돌리고, 줄바꿈 없는 공백은 보통 공백으로 바꿔 둡니다.

주소를 넣으면 그 페이지를 가져와 주나요?

가져오지 않습니다. 붙여 넣은 소스만 읽고 외부 주소에 접속하거나 다른 파일을 불러오지 않습니다. 입력은 100,000자까지이고 태그 중첩이 100단을 넘으면 오류로 알려 줍니다.

워드에서 복사한 서식이나 마크다운도 정리할 수 있나요?

워드 붙여넣기 HTML 정리로 바꾸면 문단·표·링크처럼 허용 목록에 있는 태그만 남기고 나머지 서식을 떼어냅니다. 마크다운 일반 글 변환은 제목·목록·강조 표기를 지운 글만 남깁니다.
