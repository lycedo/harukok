파일 용량 단위 변환기

사용방법 용량과 단위를 고르고 ‘용량 변환하기’를 누르세요.

0~1조 · 소수점 6자리까지 입력 · 파일을 업로드하지 않는 숫자 환산 도구입니다.

변환 결과

소수점 최대 6자리까지 반올림합니다. 아주 작은 값은 ‘0.000001 미만’으로 표시합니다.

광고

도움말

MB와 MiB는 어떻게 다른가요?

같은 파일의 바이트 수를 서로 다른 크기의 단위로 나누면 표시 숫자가 달라집니다. 이 도구에서는 KB·MB·GB는 1,000배, KiB·MiB·GiB는 1,024배로 계산합니다.

1MB와 1MiB 환산 예시

1MB는 1,000,000바이트이고, 1MiB는 1,048,576바이트입니다. 1GiB를 입력하면 1,073,741,824바이트, 1,024MiB, 약 1.073742GB가 나옵니다. 단위 이름만 바뀌는 것이 아니라 나누는 기준도 바뀝니다.

제출 사이트의 용량 제한과 비교하려면?

제출처가 정한 KB·MB의 바이트 기준을 먼저 확인하세요. 프로그램에 따라 표시 이름과 실제 환산 기준이 다를 수 있으므로, 가능하면 파일의 실제 바이트 수를 B로 넣어 비교하세요. 이 도구는 파일 자체의 용량을 줄이지 않습니다.

인터넷 속도의 Mbps도 계산하나요?

아니요. 여기서는 파일 크기인 바이트 단위만 변환합니다. 비트와 바이트는 다르며, 전송 속도나 다운로드 시간은 계산하지 않습니다. 입력값은 서버로 전송하거나 저장하지 않습니다.
